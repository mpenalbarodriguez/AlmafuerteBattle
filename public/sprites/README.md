# Coloca tus spritesheets en esta carpeta

Para que el juego cargue automáticamente tus personajes desde los archivos locales sin necesidad de subirlos a mano, guarda tus imágenes PNG aquí con estos nombres exactos:

1. `vareta.png` -> Spritesheet completo de Vareta (8 filas)
2. `caito.png`  -> Spritesheet completo de Caíto (8 filas)

Formato del spritesheet de 8 filas:
- Fila 1: Pose de victoria (1 sprite)
- Fila 2: Reposo (2 sprites), Agachado (1 sprite), Salto (1 sprite) - mirando a la derecha
- Fila 3: Salto (1 sprite), Agachado (1 sprite), Reposo (2 sprites) - mirando a la izquierda
- Fila 4: Caminar derecha (2 sprites), Caminar izquierda (2 sprites)
- Fila 5: Piña, Patada, Piña aérea, Patada aérea (mirando derecha)
- Fila 6: Patada aérea, Piña aérea, Patada, Piña (mirando izquierda)
- Fila 7: Daño (1 sprite), Bloqueo (1 sprite), Derrota/Caída (2 sprites) - mirando derecha
- Fila 8: Derrota/Caída (2 sprites), Bloqueo (1 sprite), Daño (1 sprite) - mirando izquierda
